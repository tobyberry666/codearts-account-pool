# 排错

| 现象 | 检查与处理 |
|---|---|
| Connection error / 连接被拒绝 | 双击启动入口，检查 7866 是否监听。启动脚本应使用固定安装目录；从 ZIP 内直接移动程序可能破坏旧路径。 |
| no_healthy_account | 查看账号是否禁用、冷却或刷新失效。全部账号不可用仍会报错；当前版本没有内部等待恢复。 |
| 429 / TPM / TM.00001041 | 每分钟速率或并发会话限制；不是每日额度扣完的同义词。官方 CodeArts 客户端也可能占用同一账号的限制。 |
| benefit not found | 确认该账号拥有并领取福利，刷新 /v1/models。领取成功后，如先前错误已缓存，可安全重启清除缓存。 |
| 模型不在列表或未注册 | 用 /v1/models 核对该账号模型目录和实际模型 ID；其他账号也未必拥有相同权益。 |
| NativeCommandError / RemoteException | Windows PowerShell 会把原生程序 stderr 包装成错误。看里面的实际日志内容；loaded/listening 等正常启动行也可能被这样包装。 |
| 安装时报任务权限错误 | 任务注册受本机策略限制。可用 PrepareOnly 准备文件，然后前台运行程序；需要时由电脑管理员调整任务策略。 |
| 更新时提示程序正在运行 | 先结束任务，用停止入口停代理，再运行安装器；原账号与配置保留。 |
| 显示多个文件但额度没增加 | 可能登录了同一个云端账号，或身份未能确认。多个文件不等于多份独立额度。 |

`task-proxy.log` 是运行记录，不是正式计费账单。日志里的 prompt/completion token 优先来自上游，没有时可能估算；福利余额以提供方额度接口/官方客户端为准。

安装器不会改 DSH 配置。Base URL 末尾使用 `/v1`，API 类型选择 OpenAI chat completions，密钥取本机 connection.txt。凭证与密钥不要贴到公开 Issue。
